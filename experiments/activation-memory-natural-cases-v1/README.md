# activation-memory-natural-cases-v1

Derived by retaining sources whose hand-authored important label is true, copying their text into writes.json, and copying reads.json unchanged. 26 writes, 48 known questions, eight unknown questions. This gives oracle selection, not learned importance detection. Evaluated by activation-memory-natural-write-v1 and activation-memory-natural-read-v1.

Source: `experiments/neural-statement-natural-cases-v1`

Questions and expected answers in reads.json are excluded from writer inputs. Case files are benchmark/audit artifacts.
